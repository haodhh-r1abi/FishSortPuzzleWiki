Về tài liệu này

Nguồn dữ liệu

  • APK Fish Sort Puzzle v1.4111 (triple.sorting.bubble.fish.match, Android arm64-v8a), kéo từ LDPlayer ngày 12/09/2026.
  • Unity 2022.3.62f3, IL2CPP. Export bằng HExportV2: AssetRipper dựng project Unity, Il2CppDumper lấy metadata, Ghidra giải mã 19.267 method thuộc 14 assembly.
  • Dữ liệu thiết kế lấy từ 2.970 bundle YooAsset đóng kèm APK: 1.859 dòng cấu hình màn, 1.858 file layout bong bóng, 12 bảng config gốc.
  • Phần do server quản lý đọc trực tiếp từ logcat khi khởi động game trên giả lập, cộng với việc gọi thật API bảng xếp hạng.
  • Ảnh chụp màn hình, giá IAP thật và save thật đọc trên LDPlayer 9 (Android 9, 1080×1920) ngày 06/10/2026 với tài khoản test ở level 4. Mỗi trang tính năng có mục Ảnh chụp màn hình, Bảng config gốc trong APK, Tham số server và Số liệu đo trên máy.

Độ tin cậy

  • Số liệu trong tài liệu chép từ file config hoặc từ phản hồi server thật. Chỗ nào là suy luận đều ghi rõ.
  • Giới hạn lớn nhất là obfuscation. Assembly-CSharp dùng Beebyte Obfuscator: chỉ 114 trên 408 kiểu giữ tên đọc được và toàn bộ 28 enum bị đổi tên. Các hằng số như giá booster, tốc độ hồi mạng hay ngưỡng thành tựu nằm trong hàm có tên rác nên chưa đọc được.
  • 217 method chỉ có chữ ký do hết thời gian khi giải mã.
  • Hai sự kiện đua đang bị server tắt nên chưa quan sát được một đợt thật.

Cách cập nhật

  • Ảnh chụp và bảng config gốc khai báo trong feature_extras.json; ảnh đặt ở screenshots/.
  • Sửa gdd/<Feature>.json rồi chạy python tools/gd_site.py để dựng lại web và python tools/gd_xlsx.py để dựng lại Excel.
  • Không sửa thẳng file HTML trong site/, mọi thay đổi sẽ mất khi dựng lại.
